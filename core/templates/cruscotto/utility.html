🛠 Utility

Strumenti operativi: download di template, import di dati, e altre utilita' per gestire il sistema.

Import da Excel

Servizi

Scarica il template Excel con tutte le colonne necessarie e un paio di righe di esempio. Compila il file con i tuoi servizi, poi importali nel sistema col comando manage.py importa_servizi.

⬇ Scarica template_servizi.xlsx

Stand

Scarica il template Excel per gli stand (codice, blocco, prezzo, dimensioni, allacci...). Compila e importa col comando manage.py importa_stand.

⬇ Scarica template_stand.xlsx

Come si usa l'import

  1. Scarica il template col bottone qui sopra.
  2. Apri il file con Excel o LibreOffice; cancella le righe di esempio e compila una riga per ogni servizio.
  3. Salva il file (dove preferisci) e dal terminale lancia (PRIMA in modalita' prova): 
    python manage.py importa_servizi --file <percorso_del_file.xlsx> --dry-run
  4. Se l'output e' quello che ti aspetti, rilancia senza --dry-run.
  5. I servizi con code gia' esistente per quell'evento verranno aggiornati; quelli nuovi verranno creati.
